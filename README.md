# CloudNative Task Manager

A hands-on DevOps engineering project focused on building, containerizing, securing, deploying, and monitoring a production-oriented application.

## Project Objectives

- Build and containerize a REST API.
- Configure Docker Compose for multi-container environments.
- Implement Nginx as a reverse proxy.
- Integrate PostgreSQL with persistent storage.
- Implement automated CI/CD workflows.
- Add security scanning and container hardening.
- Implement monitoring, logging, and health checks.
- Document troubleshooting and operational procedures.

## Planned Tech Stack

| Category | Technologies |
|---|---|
| Version Control | Git, GitHub |
| Containers | Docker, Docker Compose |
| Reverse Proxy | Nginx |
